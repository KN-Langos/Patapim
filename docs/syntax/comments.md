# Comments

Patapim provides two flexible comment styles to help developers document their code effectively:

## Single-Line Comments
```
// This is a single-line comment
```

- Begins with `//` and continues to the end of the line
- Ideal for brief explanations or annotations
- Can appear after code on the same line:
```
brr count = 5; // Initialize counter variable
```

## Multi-Line Comments
```
/*
    This is a multi-line comment
    that can span multiple lines
*/
```

- Enclosed between `/*` and `*/` delimiters
- Can span any number of lines

**Perfect for:**

- File headers
- Function documentation
- Temporarily disabling code blocks
- Detailed explanations of complex logic
