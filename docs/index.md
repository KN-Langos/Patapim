# Patapim Language Documentation

A lightweight, extensible language for modern development

## Welcome to Patapim
Patapim is a dynamically-typed, interpreted programming language designed for:
- Simplicity: Clean syntax that's easy to learn
- Learning: Easy to develop
- Performance: Native code integration for critical paths
- Flexibility: Mix functional and imperative styles

### Key Features
#### 🚀 Modern Syntax
- Clean, minimal syntax with optional type hints
- First-class functions and closures

#### ⚡ Native Performance
```
native "math.so" fn fastCalc();  // Integrate Zig code
```
